# Simple Interest Calculator

A simple application/script to calculate the interest earned or owed on a principal amount over a specific period.

## Formula
The simple interest is calculated using the formula:
SI = (P * R * T) / 100

Where:
- **P** = Principal amount
- **R** = Annual interest rate (in %)
- **T** = Time period (in years)

## How to Use
1. Input the principal amount.
2. Input the annual interest rate.
3. Input the time duration in years.
4. Run the calculation to get the total interest and final amount.
